# Galeria Aleatória

Galeria Aleatória é um serviço que expõe um conjunto de pinturas aleatórias a partir da API do The MET (The Metropolitan Museum of Art)
https://metmuseum.github.io/

O serviço utiliza a API do museu para obter informações sobre as obras, incluindo o título, a imagem, o nome do artista e a data.

O utilizador pode explorar as pinturas através de uma galeria com scroll horizontal.

A cada refresh aparecem pinturas diferentes.

# Setup

1. É necessário ter o node.js instalado
2. Correr no terminal:
```bash
node server.js
```
3. Abrir estes endereços no browser 

# HTML endpoint
http://localhost:3000/

# JSON endpoint
http://localhost:3000/api/paintings
